# Support

LLM-MemShare is community-supported beta software. Use GitHub Discussions or a focused issue for setup questions, reproducible defects, and feature proposals. Include the MemShare version, Rust and PostgreSQL versions, operating system, relevant configuration names with secrets removed, logs with sensitive content redacted, and minimal reproduction steps.

There is no guaranteed response time, uptime commitment, or commercial support agreement. Maintainers prioritize cross-tenant isolation, credential handling, data integrity, release failures, and regressions in documented behavior. Production deployment, backup, monitoring, capacity, and incident response remain the operator's responsibility.

Do not report vulnerabilities in public issues. Follow [.github/SECURITY.md](.github/SECURITY.md) for private reporting.

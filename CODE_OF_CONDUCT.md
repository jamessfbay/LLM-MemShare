# Code of Conduct

LLM-MemShare contributors must communicate respectfully, assume good faith, and keep technical disagreement focused on the work. Harassment, discrimination, threats, unwanted sexual attention, doxxing, and deliberate disruption are not acceptable in project spaces.

Report conduct concerns privately to the repository owner through the contact options on the owner's GitHub profile. Security vulnerabilities must use the separate private process in [.github/SECURITY.md](.github/SECURITY.md). Reports will be reviewed as promptly and confidentially as practical. Maintainers may edit or remove content, warn participants, temporarily restrict participation, or permanently ban accounts when needed to protect the community.

This policy applies to repository discussions, pull requests, issues, release channels, and project-related private communication.
